# Haliclystus antarcticus microbiome

R scripts and sample metadata supporting the manuscript on bacterial communities associated with the Antarctic stalked jellyfish Haliclystus antarcticus and the genome-based characterization of gut-derived isolate FM48a.

The 16S rRNA (V4) analyses investigate 65 tissue samples from Byers Bay and Risopatron across gut, peduncle, and tentacle compartments. 

Sequence are available: NCBI BioProject accession PRJNA1558909.
